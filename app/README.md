# app/

Ovde će biti Swift izvori i Xcode projekat.

Planirana struktura:

```text
app/
  DiktatorIOS/       glavna SwiftUI aplikacija
  DiktatorKeyboard/  custom tastatura (UIInputViewController)
  Shared/            transliteracija, modeli, pomoćne funkcije
  vendor-ios/        whisper.cpp statičke biblioteke (ne ide u git)
  pripremi-whisper-ios.sh
```

Kod se dodaje posle potvrde arhitekture i instalacije Xcode-a.
